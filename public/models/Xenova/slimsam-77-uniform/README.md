# SlimSAM 77 Uniform

This directory contains the quantized ONNX browser export of
[`Xenova/slimsam-77-uniform`](https://huggingface.co/Xenova/slimsam-77-uniform),
used for local point-prompted image segmentation.

The model is licensed under Apache-2.0. The application runs it entirely in
the user's browser; images are not sent to a segmentation service.
